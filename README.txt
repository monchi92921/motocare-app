MOTOCARE ADVANCED MOBILE WEB APP

Files:
- index.html: complete app
- manifest.json + icons: install metadata
- sw.js: offline cache support

Features:
Dashboard, multi-motorcycle garage, odometer, parts interval tracker,
service records, expense tracking, search, edit/delete, JSON backup and CSV report.
Data is saved locally in this browser on this device.

IMPORTANT iPHONE INSTALLATION:
A PWA must be served from an HTTPS website to be installable with Safari's
Add to Home Screen and to use service-worker offline caching. This ZIP cannot
install itself as a native iOS app. Upload these files to an HTTPS host (for
example GitHub Pages or another static host), open the resulting HTTPS URL in
Safari, tap Share, then Add to Home Screen.

This is a browser-based mobile prototype. It is NOT the Python/Kivy/SQLite
native mobile build specified in the approved school proposal. Keep the Kivy
project for the required technology submission; ask your instructor before
submitting this PWA as the final app.
